# APP 自动接收与动作控制

先用 `armInitialize(...)` 设置输出通道，再将蓝牙收到的文本传入 `armAppReceive(data)`。第一次接收会自动准备并启动唯一的后台循环，无需准备、更新或停止动作积木；自动准备不回位。

## 最小调用

添加 RobotShield 和 Bluetooth 扩展，使用 micro:bit V2，复制 [最小案例](../examples/arm-app-minimal.ts)。需要自定义左右 pad 动作时使用 [完整案例](../examples/arm-app.ts)。

```typescript
bluetooth.onUartDataReceived(serial.delimiters(Delimiters.Hash), function () {
    Acebott.armAppReceive(bluetooth.uartReadUntil(serial.delimiters(Delimiters.Hash)) + "#")
})
```

保留 `#` 结束符；支持半条指令分多次接收和一次接收多条。库内部完成文本转数字、XYZ 解析和调度。单条最多 96 字符，超长帧丢弃至下一个 `#`。

## 保留的 APP 积木

- 接收并解析 APP 数据。
- APP 左／右 pad 按键上／下／左／右被按下：仅查询状态，动作由用户定义。
- 选择机械臂记忆组：1～3 组。
- 机械臂返回结果事件：可将结果发送给 APP。

准备、角度文本转数字、XYZ 文本转列表、停止、更新这五个积木已移除。对应 JavaScript 接口仅保留兼容旧程序，新程序无需调用。

## 协议

所有指令以 `#` 结束，前导零必须保留。

| 指令 | 动作 |
| --- | --- |
| `1100`～`1104` | 左 pad：松开、上、下、左、右，只更新状态 |
| `1200`～`1204` | 右 pad，同上 |
| `1301`～`1304` + 角度 | 夹爪、肘部、肩部、底盘目标，保留安全限位 |
| `1401` + XYZ | 坐标移动，如 `14017,13,2#`，也支持空格分隔或九位定长数字 |
| `1501` | 回到四关节 90°，不改变 XYZ 原点 |
| `1601`／`1602`／`1603` | 开始记录／保存姿态／结束记录 |
| `1604`／`1605`／`1606`／`1607` | 单次回放／清除当前组／循环回放／停止动作 |
| `1701`～`1703` | 选择记忆组 |

每组最多 20 个姿态。滑块目标每 120ms 应用一次；XYZ 采用局部插值状态，每步最多 1°、等待 20ms，仍支持库可计算的坐标，并预检整条路径限位。XYZ 不再随速度档位变化；速度档位继续作用于普通关节、夹爪和回位。

库不依赖 Bluetooth，无法自动感知蓝牙断开。示例在断开事件中传入 `#1100#1200#1607#`，先结束残留片段，再释放按键、停止动作。按键没有松开指令时保持状态。

`onArmAppResult` 提供解析结果和错误；选组回复为 `17011`、`17021`、`17031`，主程序自行补 `#` 发送。

软件编译和模拟不能确认真实机械臂是否抖动，需要实机复测。
